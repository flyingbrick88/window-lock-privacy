# Changelog

## 0.1.0 — 2026-08-14

- Added six plain-language Windows protection checks.
- Added independent **PROTECT**, **UNPROTECT**, and **More information** actions.
- Added Windows version and access details, recent-installation review, status refresh feedback, unavailable-item filtering, and system-tray operation.
- Added guarded policy ownership, backup, verification, and conflict detection.
- Added a feedback button linked to GitHub Issues.
- Added a self-contained x64 build and user-friendly per-user installer.

This is a beta release. It is not a universal installation approval broker and is not code signed.
