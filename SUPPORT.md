# Support and feedback

Use [GitHub Issues](https://github.com/flyingbrick88/window-lock-privacy/issues/new/choose) for bugs and feature requests.

Before reporting a problem, select **Update protection status**, note the affected card and Windows edition/build, and read that card's **More information** guidance. Do not post passwords, product keys, email addresses, device serial numbers, or other personal information.

Window Lock is provided as-is without warranty. Security concerns should follow [SECURITY.md](SECURITY.md) rather than a public issue.
