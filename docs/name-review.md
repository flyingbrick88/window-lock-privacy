# Name review

Reviewed 14 August 2026.

Searches found unrelated software and repositories using “WindowLock” or “Window Lock,” including a utility for fixing new-window positions. No same-purpose Windows privacy and update-control application was identified in the reviewed results. The name is therefore descriptive, not globally unique.

The project is published as **Window Lock — Windows privacy & update control** and uses the repository identifier `window-lock-privacy` to reduce confusion. This review is a practical collision check, not a trademark clearance or legal opinion.
