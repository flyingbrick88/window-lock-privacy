# User guide

Window Lock checks selected built-in Windows policies at startup. Red cards need attention, pale green cards are protected, and unavailable cards are grouped last and can be hidden.

- **PROTECT** changes only that card's supported machine policy after confirmation and Windows administrator approval.
- **UNPROTECT** restores only a setting that Window Lock previously applied and still owns.
- **More information** explains the protected and unprotected effects, applicability, current evidence, and Microsoft documentation.
- **Update protection status** reads all statuses again and restarts the last-checked timer.
- **Recent installations** shows dated traditional uninstall records from the last 90 days. It is not a complete software inventory.
- **Send feedback** opens the GitHub issue chooser in the default browser; no information is submitted automatically.
- **Support development** opens flyingbrick88's Ko-fi page in the default browser. Supporting the project is entirely optional.

Protection can delay driver, app, or security updates. Review updates regularly. Window Lock cannot intercept every installer, initial Plug and Play driver, package manager, script, enterprise-management action, or Windows servicing path, and it does not promise an approval prompt for every installation.
