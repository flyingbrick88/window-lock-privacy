Privacy

Window Lock has no account, analytics, advertising, telemetry, cloud sync, or remote reporting. It sends no user, application, device, or diagnostic information to flyingbrick88 or any third party.

The app reads selected Windows settings and limited local installation records to show status. Results are not saved. It stores only local policy backup and ownership values required for safe UNPROTECT operations.

Feedback and documentation links open in the default browser. Nothing is submitted automatically; GitHub or Microsoft apply their own privacy terms once opened.
