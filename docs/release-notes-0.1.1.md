# Window Lock 0.1.1 beta

This update adds an optional **Support development** button inside Window Lock. It opens `https://ko-fi.com/flyingbrick88` in the default browser. Window Lock submits no information automatically, and support never affects features, privacy, or access.

The project website and README now include the same Ko-fi link.

## Download

- `WindowLock-Setup-0.1.1.exe` — recommended per-user installer
- `SHA256SUMS.txt` — SHA-256 verification value

The installer remains unsigned. Download only from this repository and verify its checksum. All limitations documented for 0.1.0 continue to apply.
