# Window Lock 0.1.0 beta

Window Lock makes selected built-in Windows privacy and update policies easier to understand and control. This first public beta includes six startup checks, independent per-card PROTECT and UNPROTECT actions, detailed guidance, status refresh feedback, a limited recent-installations view, system-tray operation, and a direct GitHub feedback button.

## Download

- `WindowLock-Setup-0.1.0.exe` — recommended per-user installer
- `SHA256SUMS.txt` — SHA-256 verification values

## Read before installing

- The binaries are not code signed, so Windows SmartScreen may show “unknown publisher.” Verify the checksum and download only from this repository.
- Window Lock does not intercept every installation path and cannot guarantee an approval prompt for every app, update, driver, script, package, or servicing operation.
- Protection can delay updates. Continue to review and install trusted security updates.
- Windows Home does not support every policy; those items appear unavailable.
- Uninstalling removes app files and shortcuts but does not reverse Windows policies. Use each available UNPROTECT action first if restoration is wanted.
